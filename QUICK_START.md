# Quick Start Guide

1. Make sure Python 3.10+ is installed on your Windows PC.
2. Double-click **`start.bat`** to set up the virtual environment, install packages, and start the local server.
3. Open **http://127.0.0.1:5000** in your browser (Chrome or Edge).
4. Use the quote form to check travel quotes or try the quick sample buttons to test different scenarios.
5. The application works completely offline after the initial setup.

To retrain the ML models locally, run **`train.bat`** and then restart **`start.bat`**.

For detailed documentation, architecture, and API details, check **[README.md](README.md)**.
